# Exemple de jeu

# Compiler

    gcc main.c -o main -lncurses -lm

# Jouer

    ./main

Controles :
- q : aller à gauche
- d : aller à droite

But du jeu :
- éviter les obstacles qui approchent
- tenir le plus longtemps

Score :
- le nombre affiché est la durée avant le prochain décalage
- plus il est bas plus votre score est meilleur
